Projet

Projet Algorithme : Jeux Vidéo

Un jeu vidéo codé en C++ avec un personnage qui se déplace dans un espace restreint avec des pièces et des obstacles. Votre but est de récupérer toutes les pièces pour débloquer la sortie, sans vous faire toucher par ces obstacles sinon la partie est terminée et vous avez perdu, sinon cas contraire vous gagnez.

Logiciels utilisés : CodeBlocks (en C++).

Projet terminé

Projet postes de Développement sur Rasberry PI

Projet consistant à créer un poste dans lequel on développe des profiles. On y attribue des permissions comme ajouter, éditer, supprimer par exemple des fichiers ou dossiers. Pour le poste, il faut configurer son interface : la date, l'horaire et son type, la langue, etc.

Logiciels utilisés : Rasberry Pi.

Projet terminé

Projet de communication Web : Site Web pour une agence de voyage

Projet consistant à créer un site web pour une agence de voyage. Dans mon cas avec mon coéquipier il fallait faire un site web pour jeu vidéo en HMTL et CSS. On a essayé de diversifier les choix en proposant plusieurs catalogues types de voyages pour convaincre les différents profils (jeunes, personnes agés, familles, couples, etc) qui souhaitent des voyages hors du communs.

Logiciels utilisés : Notepad++ (HTML, CSS).

Projet terminé

Projet Transverse : Application de média

Projet consistant à créer une application de média ou plutôt une plateforme en Java, dans laquel faut configurer une interface comme Netflix, Disney+, Amazon Prime Vidéo, et on propose plusieurs catalogues de films et/ou de séries avec bien évidemment le film ou les épisodes inclus dedans.

Il fallait réaliser en amont sa maquette pour avoir un aperçu de comment serait le rendu final.

Logiciels utilisés : Eclipse (pour la partie développement : Java), Penpot (pour la maquette).

Projet en cours

Projet Réseaux

Projet consistant à créer un réseau informatiques entre des machines, tester la connection en faisant des packages prouvant que le réseaux entre les machines est bien établi et fonctionnel.

À l'aide des terminaux lancé depuis VMMarionnet on peut alors configuer les machines en leur adressant leurs adresses et interfaces. On configure aussi des routes pour établir le réseaux entre les machines et atteindre l'internet.

Logiciels utilisés : VMMarionnet, terminal Linux (qui s'accompagne avec VMMarionnet).
